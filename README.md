# Office Joke Open — Entry v2

A tiny Python program (`main.py`) that writes a single one-line office joke
to `/output/entry.txt`, as required by the make.fun "Make the AI Judge
Laugh: the Office Joke Open" competition.

The joke:

> I scheduled a meeting about having too many meetings. It got rescheduled — everyone was stuck in another meeting.

## Run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing the joke on a single line.
